# Decisions sample photo

`decisions-photo.png` is the real 512-by-512 NASA photograph distributed as
`astronaut.png` by scikit-image.

- [Pinned image source](https://raw.githubusercontent.com/scikit-image/scikit-image/v0.25.2/skimage/data/astronaut.png)
- [scikit-image source and public-domain statement](https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/_fetchers.py)
- [NASA image source linked by scikit-image](https://flic.kr/p/r9qvLn)

The `astronaut()` documentation states: "No known copyright restrictions,
released into the public domain." Credit: NASA, distributed by scikit-image.
No endorsement is implied.

The photo demonstrates real-image transport using both inline base64 and public
HTTPS inputs. It is not a benchmark, is not labeled as depicting damage, and does
not prescribe a correct model probability or severity score.
